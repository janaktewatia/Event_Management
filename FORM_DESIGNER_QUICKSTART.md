# Form Designer - Quick Start Guide

## How to Access

1. Go to **Setup** menu in the left sidebar
2. Click on **"Form Designer"** tab to manage forms
3. Click on **"Form Templates"** tab to view saved templates

## Creating a New Form

1. Click **"Add Form"** button (top right)
2. **Step 1:** Enter form name and select an event
3. **Step 2:** Review and click **"Create Form"**
4. You'll be taken to the form editor automatically

## Using the Form Editor

### Left Panel - Elements

- **Header:** Large title text
- **Image:** Upload/embed images
- **Logo:** Brand logo positioning
- **Text:** Static text or labels
- **Field:** Interactive form fields from event

Click any element to add it to canvas.

### Canvas (Center)

- **Drag elements** to reposition
- **Click elements** to select for editing
- **Selected elements** show blue outline
- **See all elements** in Layers panel (left panel)

### Right Panel - Properties

When you select an element, modify:

**Position & Size:**

- Adjust X, Y coordinates
- Change width and height

**Appearance:**

- Text color (pick or enter hex)
- Background color
- Font size and weight
- Text alignment (left/center/right)
- Border radius, width, and color

**For Field Elements:**

- Choose which event field to map
- Displays attendee field options

## Saving Your Work

**Save Draft:**

- Status: Draft
- Can be edited later
- Not finalized

**Save Form:**

- Status: Saved
- Final version
- Shows in main table

**Save as Template:**

- Save design for reuse
- Available in "Form Templates" tab
- Use on other forms

## Form Templates

### View Templates

1. Go to **Setup > Form Templates**
2. Browse grid of saved templates
3. Search by template name

### Use a Template

1. Click **"Use Template"** on a template card
2. Create new form with that design
3. Customize as needed

### Delete Template

1. Click **Delete** button (trash icon)
2. Confirm deletion

## Form Table Features

**Columns:**

- Form Name
- Event Name
- Form Link (copy with icon)
- Created By & Date/Time
- Status badge
- Actions (Edit/Delete)

**Search & Filter:**

- Search by form name
- Filter by status (Draft/Saved/Published)

## Element Types Explained

| Element    | Use Case                                 |
| ---------- | ---------------------------------------- |
| **Header** | Form title, event name, section titles   |
| **Image**  | Decorative images, event photos          |
| **Logo**   | Company/event branding                   |
| **Text**   | Instructions, labels, descriptions       |
| **Field**  | Attendee data fields (name, email, etc.) |

## Properties You Can Customize

- **Colors:** Text & background (400+ hex colors)
- **Typography:** Font size, weight, style
- **Spacing:** X/Y position, width, height
- **Borders:** Width, radius, color
- **Alignment:** Left, center, right text alignment

## Tips & Tricks

✓ **Layer Panel:** See all elements in left panel, click to select
✓ **Duplicate:** Quickly copy element with duplicate button
✓ **Positioning:** Use exact X/Y coordinates for precise layout
✓ **Field Mapping:** Map text fields to event attendee fields
✓ **Responsive:** Design at 600x800px standard form size
✓ **Templates:** Save frequently used designs as templates

## Common Workflows

### Create Event Registration Form

1. New Form > Select Event
2. Add Header with event name
3. Add Logo/Image
4. Add Field elements for attendee data
5. Add Text field for instructions
6. Arrange and style
7. Save Form

### Reuse Successful Design

1. Find form in Form Designer table
2. Click Edit to open
3. Click "Save as Template"
4. Name the template
5. Use on future events

### Customize Template

1. Go to Form Templates
2. Click "Use Template" on desired design
3. Edit elements and properties
4. Save as new form
5. Forms table updated automatically

## Data Persistence

- All forms saved to browser localStorage
- Persists across sessions
- Auto-saves when you save
- Templates stored separately
- Forms tied to events by eventId

## Troubleshooting

**Elements not appearing?**

- Check if layer is visible in left panel
- Verify element has width/height > 0
- Ensure not positioned outside canvas

**Can't map field?**

- Verify event has attendee fields configured
- Check event selection in form details
- Refresh if needed

**Template not showing?**

- Must save form as template first
- Use "Save as Template" button, not regular save
- Check Form Templates tab

**Lost my work?**

- Check browser localStorage isn't cleared
- Forms auto-save in localStorage
- Create backup by saving as template
