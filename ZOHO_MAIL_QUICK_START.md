# Zoho Mail Quick Start

## 🚀 60-Second Setup

### Step 1: Get Credentials (2 minutes)
1. Go to https://mail.zoho.com
2. Login to your Zoho Mail account
3. Go to **Settings → Security → App Passwords**
4. Create a new app password
5. Copy the password

### Step 2: Configure in App (1 minute)
1. In your Event Management app
2. Go to **Settings → Communication Setup**
3. Click **Email** tab
4. Change provider to **Zoho Mail**
5. Paste:
   - **Email**: `your.email@zohomail.com`
   - **Password**: `[your app password]`
6. Click **Test Connection**
7. Click **Save Settings**

### Step 3: Done! ✅
Zoho Mail is now active for all emails!

## 🧪 Test It Works

1. In Communication Setup, click **Test Connection**
2. Should see: `✓ Zoho Mail connection successful!`
3. Done!

---

## 💡 Tips

- **Use App Password**: More secure than main password
- **Check Spam**: If emails don't arrive, check spam folder
- **Monitor Usage**: Zoho shows usage in account dashboard
- **Multiple Emails**: You can add multiple Zoho accounts by switching provider

---

## 🔐 Your Credentials Won't Be Shared

- Encrypted in database
- Never sent to frontend
- Only used for SMTP connection
- You control them completely
