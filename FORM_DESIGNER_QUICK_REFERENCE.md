# Form Designer & Form Templates - Quick Reference

## 🎯 What's New

### Form Designer (Setup > Form Designer)
The Form Designer now provides the same professional editing experience as the Generate Pass designer.

### Access Points
1. **Setup Page** → **Form Designer Tab**
2. **Setup Page** → **Form Templates Tab**

## 🎨 Key Features

### Canvas
- **Preset Sizes**: Card (350×200), Badge (400×600), Ticket (600×250)
- **Drag & Drop**: Click and drag elements to reposition
- **Resize**: 6-point handles (corners + edges) for precise sizing
- **Lock Elements**: Prevent accidental modifications
- **Layering**: Bring to Front / Send to Back controls

### Element Types
| Type | Use Case |
|------|----------|
| Header | Bold titles at top |
| Footer | Subtle text at bottom |
| Text | Body content |
| Image | Photos/graphics |
| Logo | Company/brand marks |
| Divider | Visual separators |

### Properties Panel

**Position & Size**
- X, Y coordinates (0-based)
- Width (W) and Height (H) in pixels

**Appearance**
- Text Color (hex or color picker)
- Background Color (with transparency option)
- Border Color, Width, and Radius
- Opacity (0.0 - 1.0)
- Z-Index (Front/Back buttons)

**Typography** (Text elements only)
- Font Family: Inter, Arial, Georgia, Courier, Verdana
- Font Size: 1-999px
- Font Weight: Thin, Light, Normal, Semibold, Bold
- Line Height: Adjustable spacing

**Text Alignment** (Text elements)
- Left | Center | Right

**Content**
- Text: Direct text input
- Image: URL input + Object Fit (Cover/Contain/Fill)

### Actions on Elements
- **Duplicate** <i class="bi bi-copy"></i>: Create identical copy offset by 10px
- **Delete** <i class="bi bi-trash"></i>: Remove element
- **Lock** <i class="bi bi-lock"></i>: Prevent accidental changes
- **Bring to Front**: Increase z-index
- **Send to Back**: Decrease z-index

## 💾 Saving

### Save Draft
- Saves work without marking as complete
- Can return and edit later

### Save Form
- Saves form as complete
- Ready for use

### Save as Template
- Creates reusable form template
- Add name and optional description
- View in Form Templates tab

## 📋 Form Templates

### View Templates
- Access: Setup > Form Templates
- Shows all saved templates as cards
- See element count and creation date

### Edit Template
- Click Edit button on any template
- View and modify:
  - Template name
  - Description
  - All elements with dimensions
  - Element content preview

### Use Template
- Click Use button
- Creates new form from template
- All elements pre-configured

## 🎯 Best Practices

1. **Use Presets**: Start with a canvas preset matching your need
2. **Lock When Done**: Lock elements you don't want to move accidentally
3. **Group Logically**: Place related elements near each other
4. **Consistent Sizing**: Use similar font sizes for readable hierarchy
5. **Save Frequently**: Save drafts as you work
6. **Create Templates**: Save complex designs as templates for reuse
7. **Use Layering**: Use Front/Back for overlapping elements
8. **Test Preview**: Check how form looks before publishing

## 🐛 Troubleshooting

| Issue | Solution |
|-------|----------|
| Can't move element | Check if element is locked (unlock it) |
| Element behind another | Use "Bring to Front" button |
| Text not visible | Check text color vs background color contrast |
| Image not showing | Verify image URL is correct and accessible |
| Changes not saving | Click "Save Form" button explicitly |

## 🔄 Workflow Example

1. Go to **Setup** → **Form Designer**
2. Click **Add Form** to create new form
3. Click form name to start editing
4. Choose **Canvas Preset** (e.g., Card)
5. Add **Elements** from left panel (Header, Text, Image, etc.)
6. Click element to select and adjust **Properties**
7. Use **Resize Handles** to size elements
8. Use **Alignment Buttons** to center/align text
9. Click **Duplicate** for similar elements
10. Click **Save as Template** to save design
11. Click **Save Form** to finish

## 📊 Element Dimensions

| Element | Default Size | Recommended |
|---------|--------------|------------|
| Header | 400×72px | Full width, 60-80px height |
| Footer | 400×48px | Full width, 40-50px height |
| Text | 200×36px | Flexible based on content |
| Image | 140×140px | Vary based on image ratio |
| Logo | 80×80px | 60-100px for visibility |
| Divider | 360×2px | Near full width, 2px height |

## 🎨 Color Tips

- **Text**: Dark colors (#1e293b, #333333) for readability
- **Background**: Light colors (#ffffff, #f8fafc) for contrast
- **Accents**: Use brand colors for emphasis
- **Borders**: Subtle grays (#e2e8f0) for definition
- **Example**: Dark text on light background ensures readability
